# Ashin K — Personal Portfolio & Engineering Showcase

A modern, high-performance, developer-focused personal portfolio website for **Ashin K**, Computer Science Engineering student specializing in **Artificial Intelligence & Machine Learning** at AJ Institute of Engineering and Technology, Mangaluru.

Designed and engineered with **React, TypeScript, Vite, and Tailwind CSS**, featuring bespoke interactive machine learning visualizers, dark charcoal aesthetics, refined micro-interactions, and 100% factual accuracy.

---

## 🚀 Live Local Development

### Prerequisites
- Node.js (v18+ recommended)
- npm or yarn

### Quick Start
```bash
# Install dependencies
npm install

# Start Vite local development server
npm run dev

# Build for production with TypeScript verification
npm run build

# Preview production build locally
npm run preview
```

The application runs on `http://localhost:5173/`.

## 🎨 Visual Design & System Architecture

- **Color Palette:**
  - Base Surfaces: Deep near-black/charcoal (`#07090E`, `#0B0F19`, `#101626`)
  - Accent Hierarchy: Electric Cyan (`#38BDF8`), Electric Indigo (`#6366F1`), and Violet (`#8B5CF6`)
  - Status & Confidence Accents: Emerald (`#10B981`)
- **Typography:** Plus Jakarta Sans & JetBrains Mono
- **Atmosphere:** Subtle CSS ambient glows, micro-grid background pattern, restrained glassmorphism, fine 1px borders, smooth scrolling, and reduced-motion accessibility support.
